fastfetch-config ships with over 150 named colors that you can assign to logo color slots 1–9. Named colors are resolved at runtime by the `resolve_color` function, which looks up the name in the internal `C` associative array and returns the corresponding hex value. If the input is not a recognized name it is passed through unchanged, so raw hex codes and ANSI codes work too.

## Using colors

```bash
ff color 1 cyan          # Named color
ff color 2 "#FF8000"     # Raw hex code (passed through as-is)
ff color 3 32            # ANSI color code (passed through as-is)
ff color list            # Show all current color overrides
ff color reset           # Clear all color overrides
ff color names           # Print every recognized color name
ff color search <term>   # Search color names by partial match
```

<Note>
  Color names are **case-insensitive** — `Red`, `RED`, and `red` all resolve to the same hex value. The source normalizes input with `tr '[:upper:]' '[:lower:]'` before lookup.
</Note>

## Input formats

fastfetch-config accepts three types of color input wherever a color is expected:

| Format | Example | Behaviour |
|--------|---------|-----------|
| Named color | `cyan` | Resolved to its hex value from the table above |
| Hex code | `#FF8000` | Passed through unchanged to the config |
| ANSI code | `32` | Passed through unchanged (fastfetch interprets it) |

<Tip>
  Not sure which color to use? Run `ff color search <term>` to find names by partial match — for example `ff color search blue` lists every color containing "blue".
</Tip>
