fastfetch-config is a terminal-based configuration manager for [fastfetch](https://github.com/fastfetch-cli/fastfetch). Use the `ff` alias or the full `fastfetch-config` command to set logos, tune display modules, assign colors to logo slots, back up your config, and more — all without manually editing JSON.

## What fastfetch-config does

<Steps>
  <Step title="Install with one command">
    Run the installer script to place `fastfetch-config` and the `ff` shortcut in `~/.local/bin`. The installer auto-detects your distro and installs `jq`, `chafa`, and `imagemagick` as needed.
  </Step>
  <Step title="Set your logo">
    Pick a built-in logo (`ff logo arch`), use a custom ASCII art file, or render a PNG/JPG with chafa (`ff chafa on`).
  </Step>
  <Step title="Tune your modules">
    Add, remove, reorder, and configure the information modules shown by fastfetch — OS, CPU, memory, GPU, disk, and more.
  </Step>
  <Step title="Customize colors and OS name">
    Override logo color slots 1–9 with any of 150+ named colors or hex codes, and optionally spoof your OS name display.
  </Step>
</Steps>

## Key features

- **Interactive TUI** — `ff tui` opens a full menu-driven interface for all settings
- **150+ named colors** — use names like `cyan`, `emerald`, `skobeloff`, or any `#RRGGBB` hex
- **Config backup & restore** — timestamped backups with diff and restore support
- **Export / import** — share configs between machines
- **Self-update** — `ff update` fetches the latest stable or testing build from GitHub
- **Doctor command** — `ff doctor` checks your environment for common issues

<Note>
  fastfetch-config works best on Arch Linux and Arch-based distributions (CachyOS, EndeavourOS, Garuda, Manjaro). It also supports Debian/Ubuntu, Fedora, openSUSE, Alpine, Void, and Gentoo.
</Note>
